# 截屏快传 Android 客户端

支持 Android 10 及以上。在同一局域网内，可以将手机选中的图片、视频和文件发到 macOS 或 Windows，也可以扫描电脑上的二维码接收文件。

## 安装和配对

1. 在电脑启动截屏快传接收端，打开控制台的配对二维码。
2. 在手机上打开发布包里的 Android APK，按系统提示允许当前来源安装应用。也可以用 USB 调试从电脑安装。
3. 让手机和电脑连接同一个可信 Wi-Fi。在手机上点击「扫码配对」，允许使用摄像头并扫描电脑上的二维码。也可以手动填写电脑显示的地址和密钥，再点击「保存配对」。
4. 配对后选择图片、视频或文件上传。同一次安装重复扫码时，电脑沿用这部手机的配对记录。

USB 调试安装命令如下。

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

「测试连接」检查电脑地址和接收端响应，上传时会验证配对码。

配对、连接测试和上传均直接连接所填的电脑地址。HTTPS 使用 Android 的系统证书校验。

## 手动上传

电脑接收端升级到 v1.0.0 后，在首页点击「选择图片上传」「选择视频上传」或「选择文件上传」。系统选择器支持多选，并向截屏快传提供所选文件的访问权限。应用向当前配对的电脑发送原文件。可用「选择文件上传」发送不常见的视频格式、无扩展名的文件和空文件。

传输中断时，可点击「继续上传」重试已暂存的文件。单个文件的大小上限由电脑接收端设置。

## 接收电脑文件

在电脑接收端生成文件下载二维码，在手机点击「扫码接收文件」并扫描。文件完成后会保存在手机的「下载」目录，可在系统文件应用里查看。同名文件会分别保存。手机会自动重试连接中断，暂停后也可点击「继续接收」。二维码失效后请在电脑重新生成。

## 上传崩溃与无响应记录

从首页进入「诊断日志」，页面会读取截屏快传最近 24 小时内的诊断记录，并将每条记录生成独立 TXT。Android 11 及以上读取系统保留的本应用 Crash 和 ANR。Android 10 可记录本应用的 Java 崩溃。

电脑接收端升级到 v0.6.0 后，选择单份或多份记录并点击上传，即可把 TXT 发到当前配对的电脑。电脑接收列表会显示「诊断日志」。未传成功的记录可以重新选择上传。诊断文件仅在手动确认后发送。

## 从源码构建

使用 JDK 17 和 Android SDK Platform 35。可以在 Android Studio 中打开本目录并构建，也可以运行项目附带的 Gradle Wrapper。

macOS 或 Linux

```sh
./gradlew assembleDebug
```

Windows PowerShell

```powershell
.\gradlew.bat assembleDebug
```

生成的调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。从终端构建时，使用 `ANDROID_HOME` 或项目的 `local.properties` 指向已安装的 Android SDK。
